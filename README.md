# تنازل

منصة إعلانات مبوبة مجانية تتكون من:

- `api`: واجهة Laravel API والنشر إلى `used.pm.sa`.
- `mobile`: تطبيق Expo / React Native للمستخدمين.

## تشغيل تطبيق الجوال

```bash
cd mobile
npm install
npx expo start
```

منصة سعودية لعرض السلع المستعملة للتنازل دون مقابل.

## النسخة الأولى

- إنشاء الحساب باسم مستخدم ورقم سري من داخل التطبيق، مع دعم دخول الحسابات الحالية بالجوال
- تصنيفات وإعلانات وصور وموقع
- البحث والتصفية
- حالات الإعلان: مسودة، منشور، مباع، مؤرشف
- Laravel API وMySQL
- تطبيق Expo / React Native

API: https://used.pm.sa/api
