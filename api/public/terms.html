الشروط والأحكام

آخر تحديث: 22 أغسطس 2026

1. قبول الشروط والعمر

باستخدام «تنازل» أو إنشاء حساب أو نشر إعلان، فإنك تقر بأن عمرك 18 سنة أو أكثر وتوافق على هذه الشروط وسياسة الخصوصية. إذا لم توافق أو كان عمرك أقل من 18 سنة فلا تستخدم الخدمة.

2. طبيعة الخدمة

«تنازل» منصة تتيح للمستخدمين عرض سلع مستعملة للتنازل دون مقابل والتواصل بشأنها. التطبيق ليس بائعًا أو مشتريًا أو وسيط دفع أو ضامنًا لأي تعامل، ولا يستلم قيمة السلع نيابةً عن المستخدمين.

3. الحساب وأمنه

  • يجب تقديم بيانات صحيحة والمحافظة على سرية الرقم السري.
  • أنت مسؤول عن النشاط الصادر من حسابك ما لم تبلغنا عن استخدام غير مصرح به.
  • يجوز تعليق أو حذف الحسابات المستخدمة في الاحتيال أو الإساءة أو مخالفة هذه الشروط أو الأنظمة.

4. قواعد الإعلانات والمحتوى

  • يجب أن يكون الإعلان صحيحًا وأن تكون لك صلاحية نظامية لعرض السلعة.
  • يُمنع المحتوى غير القانوني أو الاحتيالي أو المضلل، والسلع المسروقة أو المقلدة، والأسلحة والمتفجرات والمواد الخطرة أو المخدرات والمواد المحظورة، والمحتوى الجنسي أو الاستغلالي، والكراهية أو التهديد أو التحرش، وانتهاك الخصوصية أو الملكية الفكرية، والرسائل المزعجة أو الروابط الضارة.
  • يُمنع نشر بيانات شخصية للآخرين دون حق أو موافقة أو استخدام التطبيق لانتحال الهوية أو الإضرار بالغير.
  • يجوز حذف أو إخفاء أي إعلان أو رسالة أو حساب مخالف.

5. المحتوى الذي تنشره

تظل مالكًا للمحتوى الذي ترفعه، وتمنح المنصة ترخيصًا غير حصري ومحدودًا بالقدر اللازم لاستضافته ومعالجته وعرضه وتشغيل ميزات التطبيق، وينتهي هذا الترخيص عند حذف المحتوى إلا بالقدر اللازم للنسخ الفنية المؤقتة أو الالتزامات النظامية.

6. التواصل والصفقات

  • الاتفاق والاستلام والفحص وأي تعامل بين المستخدمين مسؤولية أطراف الصفقة.
  • تحقق من السلعة والطرف الآخر ولا ترسل أموالًا أو معلومات حساسة استجابةً لرسالة أو رابط غير موثوق.
  • لا نضمن صحة كل إعلان أو هوية كل مستخدم، مع اتخاذ إجراءات معقولة للحد من الإساءة عند اكتشافها أو الإبلاغ عنها.

7. الموقع ورقم الجوال

إضافة الموقع الدقيق وإظهار رقم الجوال ميزتان اختياريتان، ويتحمل المستخدم مسؤولية المعلومات التي يقرر نشرها.

8. الإبلاغ والإدارة

يمكن الإبلاغ عن المحتوى أو السلوك المخالف عبر a.baf@live.com. يحق للإدارة التحقيق وإزالة المحتوى أو تقييد الحسابات، ولا يمنع ذلك من اللجوء إلى الجهات المختصة عند وجود احتيال أو تهديد أو مخالفة.

9. إخلاء المسؤولية

تُقدم الخدمة كما هي ضمن الحدود المسموح بها نظامًا. لا نضمن إتمام صفقة أو جودة سلعة أو استمرار الخدمة دون انقطاع، ولا نستبعد أي مسؤولية لا يجوز استبعادها نظامًا.

10. إنهاء الاستخدام وحذف الحساب

يمكن للمستخدم حذف حسابه من داخل التطبيق. ويجوز تعليق أو إنهاء الحساب عند المخالفات الجسيمة أو المتكررة مع مراعاة الأنظمة.

11. النظام الواجب التطبيق

تخضع هذه الشروط لأنظمة المملكة العربية السعودية دون الإخلال بأي حقوق إلزامية يقررها نظام واجب التطبيق.

12. تعديل الشروط

قد نعدّل الشروط عند تطوير الخدمة أو تغير المتطلبات، وسيتم تحديث تاريخ الصفحة وقد نطلب موافقة جديدة عند التغييرات الجوهرية.
